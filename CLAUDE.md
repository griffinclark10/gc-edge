# Portfolio site

The full build brief is in `SPEC.md`. Read all of it before writing code, and treat it as the source of truth for stack, design tokens, page structure and copy. `SPEC.md` is gitignored on purpose (it holds private notes): never commit it or quote its §1/§11 notes into public files.

- Visual references: `design-reference/*.html` are static mockups to match visually. Don't copy their markup.
- Older facts and assets: https://github.com/griffinclark10/chat-gsc (clone it read-only for PDFs, images and old wording).
- Never invent metrics, dates or claims. Leave `[FILL]` / `[CONFIRM]` placeholders visible and track them in `TODO-CONTENT.md`.
- Work milestone by milestone (SPEC.md §10) and stop for review after each.
