## How it was built

Five of us built HelpingHand through QMIND, the Queen's AI student group. I worked on the Keras model and built the browser interface that ran it against a live webcam feed.

The model is a convolutional network in Keras: alternating convolution and max-pooling layers, a dropout layer against overfitting, and a dense output layer with one class per sign. Frames were converted to greyscale and resized with OpenCV and NumPy before training. Gaussian blur and edge enhancement were tried too; none of the three changed accuracy much (the differences weren't recorded), and greyscale stayed because it sped up training. J and Z were left out because they need motion.

## What we'd have done next

The paper's own conclusion: make preprocessing robust to busy backgrounds, add the motion letters, numbers and words, and move from a web page to a mobile app.
